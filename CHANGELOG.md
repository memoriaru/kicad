# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Fixed
- Board → JSON5 export dropped `zone.filled_polygons` — zones came back from
  the JSON5 hop with their copper fill silently emptied. The zone serializer
  now emits `filled_polygons: [{ layer, points }]` and the two previously
  ignored board JSON5 round-trip tests are re-enabled.
- Integration tests no longer depend on an untracked `../example_sch`
  directory: committed fixtures live in `tests/fixtures/` (generated by this
  toolchain), and tests exercising real-world boards from the HQ EDA online
  viewer demo set are opt-in via `--ignored` (see `tests/fixtures/README.md`).
- A graphics round-trip test silently skipped itself when its (product)
  fixture was absent — replaced by a real test on a committed fixture.

### Added
- PCB footprint `(model ...)` 3D model fields are preserved end-to-end:
  `Footprint.models: Vec<Model3D>` (multiple models per footprint,
  `${KIPRJMOD}` variable paths kept verbatim), `(offset|scale|rotate (xyz …))`
  sub-fields all optional with KiCad defaults, `models` array on the JSON5
  side (legacy singular `model` key still accepted), byte-level idempotent
  double-hop conversion (tested).

## 0.9.0

### Added
- S-expression lexer and parser (nested lists, all atom types, `;` comments).
- Intermediate representation for schematics (`Schematic`, `Symbol`,
  `Net`, `Wire`, `Label`, `Junction`, `Pin`, `Paper`, `TitleBlock`) and PCB
  boards (`Board`, `Footprint`, `Pad`, `Zone`, graphics, nets).
- JSON5 code generator with configurable indentation and comment support.
- S-expression generator (schematics and boards), targeting KiCad 7–10.
- Bidirectional CLI:
  - `.kicad_sch` ↔ JSON5, `.kicad_pcb` ↔ JSON5
  - `-t/--topology` circuit topology extraction
  - `--validate`, `--debug-ast`, `--kicad-version`, `--power-flags`
- Topology analysis: component classification, connectivity, circuit pattern
  recognition, power domains.
- Board-level auto-layout with grid alignment and power-flow heuristics.
- Hierarchical schematic support (sheet loading, interface label checks).
- Vendor dialect handling for HQ EDA (华秋 EDA) board files.
